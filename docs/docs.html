Using your card

Every Tokard card carries an official API key, issued by DeepSeek or BytePlus. You call the provider directly, at its own address, with its own model IDs. Tokard is never in the path of your requests.

Quickstart

  1. Get a card: flip today's three on the home page, or buy one in the shop.
  2. Open the card in your wallet. It shows three things: the key, the base URL and the model ID.
  3. Put those three into any OpenAI-compatible client. For a Coding card:

How a card works

  • The key is official. It was issued by DeepSeek or BytePlus, and it works only against their API.
  • The face value is the key's balance. Every call is billed by the provider at its own published prices. When the balance is used up, the provider refuses further calls until you refill the card.
  • Your requests go straight to the provider. Tokard never sees your prompts, files or outputs.

Chat completions

POSThttps://api.deepseek.com/chat/completions

DeepSeek uses the OpenAI Chat Completions format, so the OpenAI SDKs work as they are. deepseek-flash is DeepSeek V4.1 Flash: a 1M-token context, and it reads images.

Streaming

Set stream to true to receive the answer as it's written.

Thinking mode, tool calls, JSON output and context caching are covered in the DeepSeek API reference.

Anthropic format

DeepSeek also answers the Anthropic Messages format at https://api.deepseek.com/anthropic. Use the card's key as the API key.

Generate images

POSThttps://ark.ap-southeast.bytepluses.com/api/v3/images/generations

ModelArk's image endpoint works with the OpenAI SDK's images.generate. Set size to "2K" or to pixel dimensions; results come back as a url (valid for 24 hours) or as b64_json.

To edit, pass one or more source images in image. Every parameter is in the ModelArk image generation API.

Generate videos

POSThttps://ark.ap-southeast.bytepluses.com/api/v3/contents/generations/tasks
GEThttps://ark.ap-southeast.bytepluses.com/api/v3/contents/generations/tasks/{id}

Videos render in the background: create a task, check it until its status is succeeded, then download content.video_url. Set the length with duration (in seconds) and the quality with resolution; generate_audio adds sound.

Set duration and resolution explicitly: they decide what a video costs. Prices per second are on ModelArk pricing.

Balance and refills

A card's face value is the balance behind its key, and the wallet shows what's left. When it runs out, the provider refuses calls (DeepSeek answers 402 Insufficient Balance) and nothing more can be charged.

Refill a card from the wallet to bring it back to its face value. The key stays the same, so nothing in your code changes. Refills are priced like the shop, with the discount of the card's size.

Key safety

  • Use one card per app or project, so a problem in one never touches the others.
  • Keep keys in environment variables or a secret manager, never in source code.
  • Call the API from your server. A key in a web page or a mobile app can be copied.
  • If a key leaks, freeze the card in your wallet and move to a new card.

Errors

Errors come from the provider. The ones you'll see most from DeepSeek:

StatusMeaningWhat to do
400 / 422The request body or a parameter is invalid.Fix it using the hint in the message.
401The key is wrong.Copy it again from the wallet.
402The card's balance is used up.Refill the card in the wallet.
429Too many requests at once.Slow down and retry with backoff.
500 / 503The provider is busy or having trouble.Retry after a short wait.

Full lists: DeepSeek error codes and the ModelArk documentation.

Rate limits

Rate limits are set by each provider for every key, and they change over time. See DeepSeek rate limits and the ModelArk model list for current numbers.
