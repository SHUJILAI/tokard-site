Questions

Which models are behind text, image and video?

DeepSeek V4.1 Flash for text, Seedream 5.0 Pro (the model behind Dreamina) for images, and Seedance 2.5 for video. Always the newest version of each.

What happens when a newer version ships?

We test it, then move the model name to it. Your code keeps working. If you need a fixed version, pin it, for example text@2026-10.

Where is my data processed?

Outside China. Prompts and outputs are not stored or used for training.

Do I need a new SDK?

No. Keep the OpenAI SDK you already use and change the base URL. For Claude Code, Cursor and Cline, set the base URL and key, and use text as the model name.

How do I pay?

Add funds by card in the console, or redeem a code. Plans renew monthly and their allowance is used before your balance.
